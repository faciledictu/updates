# updates

Update feeds of eloquentcat.com apps, served by GitHub Pages at https://updates.eloquentcat.com, one folder per app:

- `tiro/appcast.xml` — Tiro, a dictation app for the macOS menu bar (Sparkle feed; the DMGs are in [tiro-releases](https://github.com/faciledictu/tiro-releases/releases))

The feeds are written by each app's publishing script; don't edit them by hand.
